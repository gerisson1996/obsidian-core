🎮 Como Funciona o NX Port Hub

O catálogo remoto distribui os metadados dos ports, informações de compatibilidade e os pacotes .nro. Nosso aplicativo para Nintendo Switch lê este catálogo automaticamente e realiza o download e a verificação SHA-256 no cartão SD.

⚖️ Distribuição Responsável

Nenhum jogo comercial ou asset protegido é distribuído pelo catálogo. Quando exigido pelo port (como arquivos default.xbe, .iso ou bigfile.bin de títulos de Xbox), o usuário final deve extraí-los a partir de sua cópia original e colocá-los no cartão SD (ex: sdmc:/switch/<jogo>/game/).

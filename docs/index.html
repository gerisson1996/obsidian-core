NX Port Hub

Um catálogo simples para descobrir ports comunitários, consultar informações e acompanhar atualizações para Nintendo Switch.

Abrir catálogo JSON Ver projeto no GitHub

Como funciona

Este site publica os dados do catálogo. Os pacotes de cada port serão disponibilizados separadamente, quando estiverem configurados. O app homebrew NX Port Hub será um componente separado; esta página ainda não instala nem executa jogos.

Distribuição responsável

Compartilhe apenas arquivos que você tem autorização para distribuir. Quando um port exigir dados proprietários do jogo, o usuário deverá prepará-los a partir de sua própria cópia legítima, conforme as instruções do projeto.

Projeto comunitário independente. Não afiliado à Nintendo.
